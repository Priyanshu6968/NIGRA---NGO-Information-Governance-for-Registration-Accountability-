NIGRA

NGO Information Governance for Registration & Accountability

Project Report | January 2026

1. Project Overview

Objective: Design and develop a secure backend-driven system for NGO registration and donation management that separates user registration from donation flow, ensuring data integrity, transparency, and ethical payment handling.

Key Features

  • Role-based authentication (Donor, NGO, Admin)
  • Razorpay payment gateway integration (Sandbox)
  • Donation tracking with status management (Success/Pending/Failed)
  • Admin dashboard with statistics, filtering, and CSV export
  • Registration data preserved regardless of payment outcome

5. Key Design Decisions

Data Integrity First

Registration data is stored independently of payment completion. Users are saved to the database immediately upon registration, ensuring no data loss if payments fail.

Payment Verification

  • Razorpay signature verification using HMAC SHA256
  • No fake success logic - status based solely on gateway response
  • Failed payments recorded with full tracking details

Role-Based Access Control

  • JWT tokens contain user ID, decoded on each request
  • Middleware checks role before reaching controllers
  • Admin endpoints protected with ADMIN role check

Assumptions

  • Single NGO per user account
  • INR currency for all transactions
  • Minimum donation amount: ₹1
  • Admin accounts created via seed script
