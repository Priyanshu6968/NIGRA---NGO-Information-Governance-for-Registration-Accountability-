# NIGRA: NGO Information Governance for Registration & Accountability

NIGRA is a secure, transparent, and efficient system designed for NGO registration and donation tracking. It ensures accountability by providing a centralized platform for NGOs, Donors, and Administrators.

## 🚀 Features

- **NGO Registration & Verification**: Streamlined process for NGOs to register and get verified by admins.
- **Secure Donation Tracking**: Transparent tracking of donations from individuals to NGOs.
- **Role-Based Dashboards**: Customized interfaces for NGOs, Donors, and Administrators.
- **Financial Governance**: Built-in accountability measures to ensure funds are used effectively.

- **Backend**: Node.js, Express.js, MongoDB (planned)
- **Frontend**: Vanilla HTML5, CSS3, JavaScript
- **Security**: JWT Authentication, Bcrypt password hashing
